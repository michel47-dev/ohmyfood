# OhMyFood - Site de réservation de menus gastronomiques

## Description
Projet réalisé dans le cadre de la formation OpenClassrooms Intégrateur Web.

OhMyFood est un site de réservation de menus pour des restaurants gastronomiques.

Le projet a été développé en mobile first avec des animations CSS et du SCSS.

---

## Fonctionnalités
- Intégration complète de maquettes Figma
- Animations CSS
- Loader de chargement
- Animation des menus
- Effets hover
- Bouton “j’aime” animé
- Responsive mobile et desktop
- Navigation entre les pages

---

## Technologies utilisées
- HTML
- SCSS
- CSS Animations
- Flexbox
- Responsive Design
